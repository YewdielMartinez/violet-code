# Registro de descubrimiento

Documentos vivos. Se actualizan durante y después de cada reunión con SEMUJERES.

| Documento | Qué registra |
|---|---|
| [hipotesis.md](hipotesis.md) | Hipótesis y su estado (abierta / confirmada / refutada / parcial). |
| [acta-reunion.md](acta-reunion.md) | Plantilla por reunión: respuestas por pregunta (Q-xx), citas, documentos recibidos. |
| [requerimientos.md](requerimientos.md) | Requerimientos confirmados y descartados, con trazabilidad a la evidencia. |
| [decisiones-pendientes.md](decisiones-pendientes.md) | Decisiones abiertas, qué las bloquea, fecha límite. |
| [riesgos.md](riesgos.md) | Riesgos de producto, técnicos, de seguridad y de calendario. |
| [cambios-arquitectura.md](cambios-arquitectura.md) | Bitácora de cambios a la arquitectura preliminar (enlaza ADRs). |

## Convenciones

- **IDs estables:** `H-` hipótesis · `Q-` pregunta · `R-` respuesta · `RF-` requisito funcional · `RNF-` no funcional · `RD-` descartado · `D-` decisión pendiente · `K-` riesgo · `AC-` cambio de arquitectura · `ADR-` decisión registrada.
- **Certeza:** `[C]` confirmado por SEMUJERES · `[H]` hipótesis del equipo · `[I]` inferido de una respuesta (reconfirmar).
- **Nunca** registrar datos personales reales ni detalles identificables de casos. Si se cuenta un ejemplo, anonimizar al anotar.
